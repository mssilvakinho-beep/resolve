# RESOLVE 2.0 — Cérebro IA + confirmação

A camada de IA é opcional: sem `OPENAI_API_KEY`, o sistema usa o interpretador local; com a chave, usa a API da OpenAI e mantém a mesma regra: **IA propõe, usuário confirma, sistema registra**.

Fluxo: mensagem → interpretação → proposta pendente → confirmação → persistência.

Não há necessidade de crédito da OpenAI para executar o modo local. Para usar a IA real, é necessário saldo de API.
